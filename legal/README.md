# legal/

ストア審査に必須の静的ページの草案（本番リリース計画書 §5.1・§5.3・RI-02）。
プライバシーポリシー・利用規約・Google Play 向けのアカウント削除導線の 3 枚 + 目次。

## 公開前に必ずやること

1. 各ページ冒頭の「草案」注記どおり、運営主体名・住所・連絡先・準拠法を実際の値に置き換える
2. 弁護士等の専門家によるレビューを受ける（AI が生成した草案であり、法的な確認を経ていない）
3. どこかにホスティングする（Cloudflare Pages 等を想定。RI-02: LP と法務ページの公開先確定）
4. ストア申請の「プライバシーポリシー URL」「サポート URL」欄にホスティング後の URL を設定する
5. `apps/mobile` のオンボーディング・設定画面からもリンクする

## ローカルでの確認

ビルド不要の素の HTML。ブラウザで直接開くか、`npx serve legal` 等で確認できる。
