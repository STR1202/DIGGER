## この実装が今どこまで v3.3 に追随しているか

`../../README.md` の「実装済みと未実装」を参照。要点だけ書くと：

- **FR-01 / FR-01b の検索二層化（グラフの有無）は `packages/core` に実装済み**。
  モックデータに `hasGraph: false` の長尾アーティストを追加し、
  `resolveViewType()`（`packages/core/src/map.ts`）が「関連アーティストを頼まれたが
  グラフが無い」ケースを黙って `genre` 表示にフォールバックする。
  `ViewTypeSwitch` はこのとき「関連アーティスト」タブを鍵アイコン付きで無効化する。
- **expo-sqlite（v3.1 の端末データストア）は未実装**。現状は MMKV
  （`apps/mobile/src/state/store.ts`）で履歴・ブックマーク・チェック済みを永続化しており、
  機能的には近いが、SQL・FTS5・`synced` フラグによる差分同期は無い。
- **Apple Music Feed のデータパイプライン（§6.2.1）は未実装**。
  `services/api` はまだ `music_v1` 相当の PostgreSQL スキーマ止まりで、
  `uid`/`mbid`/`apple_id`/`source`/`merged_into` の分離（§7.1.0, ADR-27）は
  スキーマにもコードにも反映していない。API 側は `has_graph` 列だけ追加済み。
- 詳しいギャップは本メッセージの production-readiness チェックリストを参照。
